# research

Phase one of the book. Nothing here is a chapter. Notes are dated (`2026-11-<slug>.md`) and start
from a template (`scaffold <book> <kind> --name "..."`):

| kind | prompt | what it answers |
|---|---|---|
| borrow | R2-borrow-scan.md | how other worlds already solved the book's core problem |
| coverage | R3-coverage-grid.md | are we covering the whole space? (grid or breadth checklist, scored) |
| analogy | R4-analogy-gap-fill.md | the author's "X is like Y", researched, with where it breaks |
| scorecard | R5-research-scorecard.md | which famous findings hold, are contested, or are misread |
| theory | R6-theory-builder.md | propositions with falsifiers, dated predictions, a decision rule |

Every note ends with a `## Sources` table (`| key | citation | url | status | how |`). Status is
`verified` (say how), `confirm-before-print`, or `secondhand` (say via what). `ingest-research`
turns those rows into registered sources (`S###`) a chapter can cite later.
